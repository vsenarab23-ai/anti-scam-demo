# Anti-Scam Demo

Учебная серверная демонстрация. Форма вызывает `/api/demo`, но значения полей намеренно не передаются и не сохраняются.

## Локальный запуск

```bash
npm install
npm start
```

Откройте http://localhost:3000

## Публичный запуск

Загрузите проект в свой GitHub-репозиторий и создайте на Render Web Service.

Build Command: `npm install`
Start Command: `npm start`

Render выдаст публичный `onrender.com` адрес.
